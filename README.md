# Monitoring-Lab5
# Мікросервісний моніторинг та централізоване логування (Elastic Stack & Kibana)

Реалізація системи централізованого збору, структурування та аналізу журналів подій для розподілених мікросервісних застосунків на базі **Elastic Stack (Elasticsearch, Filebeat, Kibana)** та **FastAPI**.

Проєкт розроблено в рамках лабораторного практикуму з дисципліни **«Моніторинг та аналіз даних у production-середовищах»**.

---

## 📌 Архітектура рішення

Система складається з ізольованих контейнерів Docker, об'єднаних спільною віртуальною мережею:

1. **`auth-service`** (`FastAPI`, порт `8001`) — сервіс автентифікації користувачів. Генерує події входу (`INFO`), невдалих спроб авторизації (`WARN`) та штучні збої підключення до бази даних (`ERROR`).
2. **`order-service`** (`FastAPI`, порт `8002`) — сервіс створення замовлень. Логує транзакції (`INFO`), сповіщення про вичерпання товарів (`WARN`) та помилки інтеграції з банківським шлюзом із повним стек-трейсом (`ERROR`).
3. **`filebeat`** — легкопереносний агент збору логів. Моніторить спільний том `/var/log/apps/*.log`, розбирає JSON-поля та відправляє події до Elasticsearch.
4. **`elasticsearch`** (порт `9200`) — розподілене сховище повнотекстового пошуку та індексації даних.
5. **`kibana`** (порт `5601`) — вебінтерфейс для пошуку (KQL), фільтрації подій та побудови аналітичних дашбордів.
